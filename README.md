# Steve Control

מערכת Android לניהול ושליטה מרחוק גלויה במכשירים משויכים, עם ממשק שולט וממשק מכשיר נשלט.

## החלטות מוצר
- **Android בלבד** בשלב זה. אין תמיכה ב־iPhone או ב־iOS בתוכנית הנוכחית.
- שני תפקידים: שולט ומכשיר נשלט.
- ניתן לשייך מכשיר באופן גלוי ומאובטח באמצעות קוד חד־פעמי.
- לאחר צימוד והרשאות מתאימות, השולט יוכל לשלוח פקודות נתמכות; במכשיר הנשלט יוצג שהתקבלה פקודה ושהמסך משתנה.

## יכולות מתוכננות
- לוח שליטה למספר מכשירים.
- פתיחת אפליקציות ואתרים מאושרים במכשיר המשויך, בכפוף ליכולות Android.
- תור פקודות מאובטח, סטטוס ביצוע ויומן פעילות שקוף.
- פרופילים והרשאות נפרדים לשולט ולמכשיר הנשלט.
- מצב מורה עתידי עם הרשאות מוגבלות למכשירים שנרשמו לכיתה.

## גבולות טכניים ובטיחות
היקף השליטה תלוי בגרסת Android, ביצרן המכשיר, בהרשאות ובמצב ההרשמה. האפליקציה לא תסתיר שליטה ולא תעקוף מנגנוני אבטחה. פעולות כמו הפעלת אפליקציה אחרת מרחוק, קיוסק או אכיפת מדיניות מערכת דורשות API והרשאות Android מתאימים; אפליקציית Expo רגילה אינה מקבלת שליטה מלאה במכשיר.

## מצב הפרויקט
הפרויקט נמצא בפיתוח. מסד הנתונים, אימות השולט וצימוד המכשיר קיימים כבסיס; לוח הפקודות והביצוע במכשיר עדיין דורשים מימוש ובדיקות על מכשירי Android אמיתיים. אין לראות בשם החדש כהוכחה לכך שכל יכולות השליטה כבר פעילות.

## אפליקציית Android
קוד האפליקציה נמצא בתיקיית apps/android ומבוסס Expo + React Native.
